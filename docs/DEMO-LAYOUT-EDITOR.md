# 기본 데모의 배치 저장과 지표 설정

기본 웹 데모에서 지표·패널·축의 배치와 지표 설정을 파일로 저장하거나 이 브라우저에 기억할 수 있습니다. 기존 **도형 저장 / 불러오기**와 별도 기능입니다.

## 배치 저장과 복원

- **배치 파일 저장**은 현재 패널 순서, 축 설정, 시리즈의 표시·색상·굵기와 지표 정의·파라미터를 `barochart-layout.json`에 저장합니다.
- **배치 파일 불러오기**는 파일의 배치를 현재 시세에 적용합니다. 현재 도형 객체와 Undo/Redo 이력, 선택, 시간 범위와 follow 상태를 유지합니다. 제거되거나 이동한 시리즈에 연결된 도형은 기존 [orphan 계약](INDICATOR-PLACEMENT.md)에 따라 숨겨질 수 있습니다.
- **이 브라우저에서 배치 기억**이 켜져 있으면 성공한 설정 변경을 잠시 모아 자동 저장합니다. 시세 스트림, 렌더링, 팬·줌과 도형 편집만으로는 배치를 다시 저장하지 않습니다.
- 다시 방문하면 저장한 시장·봉 수·테마와 배치를 복원하고, 해당 시장의 합성 시세를 새로 생성합니다. 스트림으로 변경된 시세, 도형, 도형 이력과 viewport를 복원하는 세션 저장 기능은 아닙니다. 도형을 보관하려면 기존 **도형 저장**을 사용합니다.
- **저장된 배치 지우기**는 기억 설정을 끄고 저장한 배치를 제거합니다. 현재 화면은 유지하며 다음 방문에는 기본 배치로 시작합니다. 저장소가 차단되거나 쓰기가 실패하면 기존 저장값과 체크박스 상태를 유지하고 오류를 알립니다.

배치 준비는 Worker에서 수행하며, 확인되지 않은 결과는 기존 차트에 설치하지 않습니다. 잘못된 파일, 취소, 시세·설정 변경, 충돌하는 도형 축 바인딩과 현재 데이터에 적용할 수 없는 축 범위는 기존 차트를 유지한 채 거부합니다. 불러오는 중 도형 이력이 달라져도 설치 직전에 최신 참조를 확인합니다.

도형 때문에 필요한 이전 패널·축은 보존합니다. 데이터가 없는 도형 축은 필요한 경우 이전 범위를 임시로 유지하며, 다시 지표가 사용하면 자동 범위를 복원합니다. 직접 지정한 범위와 명시적으로 가져온 빈 패널·축은 자동 정리 대상과 구분합니다.

## 지표별 설정

**지표 설정**에서 기본 지표와 추가 지표를 선택할 수 있습니다.

- 기간, 빠른/느린 기간, 평활 값, 배수와 지원되는 가격 소스 등을 입력하고 **매개변수 적용**을 누릅니다. 35개 내장 지표의 설정을 지원하며, OBV·ADL처럼 조정할 파라미터가 없는 지표는 이를 표시합니다.
- 변경은 `setIndicatorParamsAsync`로 선택한 지표만 계산합니다. 기존 차트·원본 데이터·다른 지표·시리즈 배치·스타일·도형 이력을 유지하고, 실패나 취소 시 기존 결과를 유지합니다. 계산 중에는 스트림을 잠시 멈추고 기존 실행 의도를 복원합니다.
- **기본값으로 초기화**는 입력 초안만 바꿉니다. 적용 버튼을 눌러야 계산에 반영합니다. Ichimoku 표시 offset처럼 출력 구조를 바꾸는 값은 읽기 전용이며, 이미 활성화된 VWAP 세션/밴드 구조 안에서 편집합니다.
- 출력별 색상·선 굵기·표시 여부를 바꿀 수 있습니다. 같은 출력에 연결된 시리즈가 여러 개면 각각 선택합니다. 색상을 직접 바꾸지 않은 굵기·표시 수정은 기존 투명도를 유지합니다.
- **이 지표와 모든 출력 제거**는 선택한 지표 그룹만 제거합니다. 사용하지 않는 데모 생성 패널·축을 정리하고 도형·이력이 참조하는 자원은 유지합니다.

입력 초안은 렌더링과 스트림 갱신 중에도 유지합니다. 작업 후 포커스는 활성 컨트롤로 복원하되, 이후 사용자가 선택한 다른 포커스를 덮어쓰지 않습니다.

## 배치 기록

기본 데모의 **배치 되돌리기**(`layout-undo`)와 **배치 다시 실행**(`layout-redo`)은 지표 그룹 배치, 새 패널로 분리, 패널 순서를 최대 30개의 메모리 명령으로 복원합니다. 같은 상태를 만든 변경은 명령을 추가하지 않고 redo를 유지하며, 효과가 있는 새 배치는 현재 위치 뒤의 redo를 버립니다.

배치 기록은 도형 기록과 별개입니다. 도형 Undo/Redo와 `Ctrl/Cmd+Z` 동작은 그대로 두고, 배치 탐색은 최신 시세 데이터, 지표 파라미터와 출력 스타일, 현재 보이는 범위를 유지합니다. 도형 이력이 참조하는 이전 패널·축도 정리하지 않고 유지합니다. 배치 기록 자체는 저장하거나 내보내지 않습니다.

모델 교체를 수반하는 로드(시장·봉 수 변경과 저장 배치 복원), 배치 파일 불러오기, 지표 추가·제거, 가격 축 스케일 편집은 배치 기록을 초기화합니다. 지표 파라미터·출력 스타일, 테마, 스트림 갱신, 같은 모델에서 렌더러만 바꾸는 작업은 초기화하지 않습니다. 적용 중 콜백이 부분적으로 실패하면 원자적 롤백을 보장하지 않으며, 실제 모델 상태를 다시 읽어 기록을 재기준화합니다.

## 파일과 실행 범위

파일은 예제 전용 `barochart.main-demo-layout` v1 형식이며 최대 512 KiB입니다. SDK [workspace](WORKSPACES.md)의 데이터 동일성 조건을 변경하지 않습니다. 내장 지표와 제한된 표시 메타데이터만 받으며, 실행 코드·외부 시리즈 값·formatter·모듈 정의·알 수 없는 필드는 거부합니다. 선택적 `managed` 메타데이터는 자동 정리가 허용된 패널·축 ID를 기록하며, 없는 파일은 명시적 자원으로 취급합니다.

브라우저 저장 키는 `barochart.main-demo.layout.v1` 하나입니다. 원본 OHLCV, 도형과 인증 정보는 배치 파일이나 이 키에 넣지 않습니다. 라이브러리의 공개 API, native command와 workspace 형식에는 변경이 없습니다.

검증 명령:

```sh
npm test
npm run test:indicator-layout:browser
npm run test:customization:browser
```

Chrome 검사는 실제 Worker 계산, 배치 파일 적용·오류, 현재 시세·도형 보존, 새로고침 복원, 자원 소유권, 저장 실패와 포커스를 다룹니다. 320/390/1280 CSS 픽셀 화면도 검사합니다. 실제 터치 기기와 스크린 리더 검증은 별도입니다.
