# Rust 데이터·수집 기반 검증 — 2026-11-04

공개 기본 backend는 JavaScript다. 이번 단계는 Rust 내부 선택자의 실제 OHLCV 소유·입력·batch·ingestion을 연결하며, 전체 차트나 기본값 전환 결과가 아니다. 모델·지표·view invalidation과 scene/interaction/workspace job 연결은 M3~M6, 실기기 성능·기본값 관문은 M7에 남아 있다.

## 연결 범위

- Contracts와 무손실 checkpoint codec, range/block index, store의 6종 data event와 atomic batch. 숫자 방언·WTF-16·선택적 own undefined·키 순서·검증 우선순위를 유지한다.
- Runtime별 store serial을 Engine에 보존한다. `nativeInit`이 후보 store를 만든 뒤 실패해도 serial은 소비하고 이전 live data는 보존하며, 반환 count의 `-0`를 유지한다.
- Retained store/columns identity는 이동을 허용하고 clone·열 교체를 구분한다. Internal staged commit은 동일 store owner를 유지한다.
- 100개 native 이름을 known implemented/reject/pending으로 분류한다. `supports`는 정의 여부이며 실행 준비 여부와 다르다. nativeCommand 65개 arity 중 데이터·수집 13개를 연결했다. Custom JS source는 정확한 UnavailableError/code로 거절한다.
- Native 데이터·수집 봉투는 단일 Engine의 실제 store/queue를 사용한다. Swift value-only realm, JNI backend 분기, 기존 ABI/host 상태 머신을 유지하며 JS fallback은 없다.

Stateful 대조는 시나리오마다 실제 JS 번들 VM과 WASM Engine을 한 번씩 만들고 같은 수명에서 재사용한다. Plain-data 인자는 VM realm 안에서 다시 만들며, undefined·NaN·Infinity·-0·own __proto__·WTF-16과 오류 name/message/code를 보존한다. Leaf `.leaf.jsonl` 검증과 native bridge 시나리오는 분리한다.

첫 전체 Node 실행은 변경된 Rust 소스에 비해 예전 크기 보고서가 남아 1건 실패했다. 리뷰 수정까지 포함한 현재 소스로 matrix를 재측정하고 최종 전체 5,960/5,960로 확인했다. 패키지 검증 첫 호출의 TSC_PATH 누락도 수정한 환경으로 재실행했다.

## 발견·수정한 실제 차이

- setColumns reset change의 own `added: undefined`와 setData reset의 absent key, append의 absent added를 구분했다.
- Legacy prepend timestamp 비교와 correction lowerBound는 이후 OHLCV 검사보다 먼저 JS coercion을 수행한다. empty-store short circuit, 원시 nullish property 오류, 배열 bar의 typeof-object 의미를 고정했다.
- Ingestion drain의 explicit undefined가 JS default parameter와 같게 동작한다.
- WASM32 aggregate의 bucket × span 정수 곱이 32비트를 넘으면 행을 누락했다. 실제 WASM 131,072행/65,536 bucket 재현으로 고정하고 중간 곱을 u64로 바꿨다.
- WASM 결과의 fatal UTF-8 decode가 실패할 때 owned buffer를 해제하지 않았다. decode를 finally 보호 안으로 옮기고 실제 allocation 수/bytes가 복원되는지 검증했다.
- Batch unchanged 판정을 위해 만들던 중복 full-store clone을 제거했다.
- 정의되지 않은 native 이름은 iOS missing, Android `TypeError: not a function` host 경로를 유지한다.

## 크기와 남은 관문

[현재 크기 matrix](2026-11-04-rust-core-size.md)는 source SHA `35efddd84ea0b2e7301b8c6868dbc57aca707f00670cb9060375932ec74591bb`에 대응한다. Shipping dual .so는 arm64 2,766,568 bytes, x86_64 2,872,768 bytes이며 각각 3,145,728-byte 예산 안에 있다. iOS 최소 executable linked delta는 738,888 file bytes / 524,288 __TEXT bytes다. 이는 전체 이식 크기·IPA 크기·속도 개선 측정이 아니다.

전체 per-engine allocation accounting, typed F64 transport/trace, packet, source job 수명·panic/EH, 최종 기능 manifest와 native chart 대조는 후속 단계다. 연결된 실기기의 차트 시작/pan 측정과 수동 화면 낭독기 검증은 아직 수행하지 않았다. 공개 tag·registry 업로드는 하지 않았다.

로컬 상세 실행 기록은 ignored `artifacts/m2a/`에 있다. GLM 8개와 DeepSeek v4-pro 8개 패킷 응답을 모두 읽고 원본 코드·재현 테스트로 판정했다. 16개 응답의 byte 수와 SHA-256도 확인했다. GLM 모델 식별자는 도구에서 공개하지 않았다. Qwen은 앞선 보호 실행기의 로컬 설정 실패 이후 이번 라운드에서 호출하지 않았다.
