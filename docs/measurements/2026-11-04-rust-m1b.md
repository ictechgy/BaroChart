# Rust M1b integration verification — 2026-11-04

M1b builds the native ABI, packaging and internal selection infrastructure. It implements only `nativeInit` count validation/echo. JavaScript remains the public default, and Rust never falls back to it. This is not a chart backend, parity result, speed comparison or default-backend rollout.

## Implemented boundaries

- One `Engine`/`Host` scaffold, bridge table and C ABI. Monotonic opaque tokens, live-only registry and active leases preserve stale-handle rejection, repeated free and deferred release. Buffer allocations have explicit ownership; callback function code and context must remain valid through terminal release, while the original callback-table struct is copied at creation. Panic poison, busy/reentry and release-once behavior have native ABI tests. Unsafe code is confined to FFI.
- A pinned project-local cbindgen 0.29.4 tool with isolated installation environment, deterministic header freshness and actual C11 compile/link/run. The native header retains its Task 6 ABI; the incompatible WASM constructor/imports are excluded.
- Local iOS XCFramework slices, optional SwiftPM binary target, internal Rust factory, Foundation timezone callbacks and a value-only JSC realm. The realm restores `JSValue` coercions/UTF-16/own-key semantics for raw calls and tracing without loading the chart bundle. Public `context` access remains unavailable on Rust.
- Android tagged JNI dispatch, same-backend isolated runtimes, timezone callbacks, unavailable classification, dual/JS-only/Rust-only builds and R8 rules. Missing backends report explicit errors. The normal API still creates JavaScript engines.
- A real WASM cdylib and V8/Intl imports. The harness checks exact import/export surfaces, memory growth, bad linear-memory ranges, allocation recovery and exactly-once release. Debug-only probes prove actual math/timezone call-through; release builds do not expose them.

## Size and failure evidence

The [fresh isolated size matrix](2026-11-04-rust-core-size.md) and [machine report](rust-core-size.json) record source/profile/tool/artifact identity. All 29 stored artifact sizes and SHA-256 values were independently checked. Shipping dual `.so` bytes are 2,468,536 (arm64) and 2,550,016 (x86_64), within the 3,145,728-byte budget. The minimal iOS executable's linked delta is 509,664 bytes / 360,448 `__TEXT` bytes. Archive size and future-port scenarios are separate; none establishes a final chart footprint or speed ratio.

The original Swift adapter's raw-call and UTF-16 string regressions were reproduced, then repaired through the design's value-only realm. Header generation initially dropped native declarations/mixed constructors after WASM integration; the final header is byte-identical to the native Task 6 header. An empty Android catch was replaced with an explicit fixed-status path and tested in the emulator.

The [JSON oracle investigation](2026-11-04-node-json-oracle.md) isolates a two-parse Node 26.5.0 failure outside Rust. Verification explicitly selects Node 22 through `PATH`; the conformance CLI rejects the observed broken runtime before Rust comparison. No Rust expectation or divergence exemption was changed.
