> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 차트 기능은 아직 없다. 대신 Rust 백엔드의 바닥 세 가지를 깐다.
- JS와 비트·바이트 단위로 같은 의미 커널
- 두 플랫폼에 붙는 빈 엔진(C ABI)과 빌드·패키징

**Architecture:** PR 세 개로 나눈다.
- **M1a** (`feat/rust-m1a-js-kernel`, Task 1~4): `rust/` 워크스페이스와 `barochart-js` 커널, V8·JSC·QuickJS 대조 하네스. 플랫폼 코드와 무관하다. M0와 병렬로 진행한다.

## Global Constraints

- **툴체인**
  - Rust는 rustup 1.98.1이다. 이 Mac은 Homebrew rustc가 PATH 앞에 있어 rustup을 가린다. 그래서 모든 cargo 호출은 `node scripts/rust/cargo.mjs <args>`로 한다. 이 래퍼가 `$HOME/.cargo/bin`을 PATH 앞에 두고 cwd를 `rust/`로 둔다(`rust-toolchain.toml` 적용).
  - Android 링커: `~/Library/Android/sdk/ndk/29.0.14033849/toolchains/llvm/prebuilt/darwin-x86_64/bin/{aarch64,x86_64}-linux-android26-clang`. `CARGO_TARGET_*_LINKER`로 지정한다. cargo-ndk는 쓰지 않는다.
- **런타임 의존성은 `ryu-js = "=1.0.3"`뿐이다.** 빌드 도구로 `cbindgen`(빌드 의존성 또는 CLI)을 허용한다. 다음은 쓰지 않는다: serde, regex, chrono, libm 크레이트. npm 의존성도 새로 넣지 않는다.
- **코드 규칙**
  - `barochart-core`, `barochart-bridge`: `#![forbid(unsafe_code)]`. `unsafe`는 `barochart-ffi`에만 둔다.
  - 모든 `extern "C"` 함수는 `catch_unwind`로 감싼다.
  - 빌드 프로필: `lto = "fat"`, `codegen-units = 1`, `panic = "unwind"`, `opt-level = "s"`(기본)
- **문서 규칙:** 주석은 한국어, 식별자는 영어다. 공개 Swift/Java API 문서 주석은 영어다. 모든 공개 Rust 항목에 문서 주석을 단다.
- **CI 금지 규칙(`scripts/rust/check-bans.mjs`):** `barochart-core`와 `barochart-bridge`에서 다음을 쓰면 실패한다.
  - `format!`/`write!`의 `{:.N}`·`{:e}` 정밀도 포맷
  - `f64::min`/`max`/`round`/`signum`
  - `mul_add`, `.trim()`, `serde`
  - 커널(`barochart-js`)은 정확한 자릿수 추출에 한해 `{:.766e}`를 쓴다.
- **산출물:** `rust/target/`과 빌드 산출물은 커밋하지 않는다(`.gitignore`). 생성 헤더 `rust/include/barochart_core.h`는 커밋하고, CI에서 최신 상태인지 검사한다.
- **iOS 배포:** M1~M6 동안 Rust 바이너리를 git에 넣지 않는다. GitHub 릴리스 자산으로 올리지도 않는다.
  - `Package.swift`는 환경 변수 `BAROCHART_RUST_XCFRAMEWORK`가 가리키는 로컬 XCFramework가 있을 때만 `binaryTarget`을 더한다.
  - 소비자 배포 방식은 M7 전에 주인에게 묻는다(커밋한 바이너리 또는 릴리스 자산).
- **커밋:** Conventional Commits, 본문 한국어, 끝 줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 커밋 전에 `npm run check`, `npm run check:types`, `node scripts/rust/cargo.mjs fmt --check`, `node scripts/rust/cargo.mjs clippy --workspace --all-targets -- -D warnings`를 통과시킨다.
- **디스크:** `rust/target`은 수 GB까지 커진다. PR마다 끝나면 `node scripts/rust/cargo.mjs clean`을 한다.

```rust
/// WTF-16 문자열. 단독 서로게이트를 담을 수 있다(코어가 slice로 쌍을 가를 수 있으므로).
#[derive(Clone, PartialEq, Eq, Hash, PartialOrd, Ord, Default)]
pub struct JsString(Vec<u16>);
impl JsString {
    pub fn from_str(s: &str) -> Self;
    pub fn from_utf16(units: Vec<u16>) -> Self;
    pub fn len_utf16(&self) -> usize;                       // .length
    pub fn slice(&self, start: isize, end: Option<isize>) -> JsString; // String.prototype.slice 의미
    pub fn trim(&self) -> JsString;                          // JS 공백 표
    pub fn to_lowercase(&self) -> JsString;                  // String.prototype.toLowerCase
    pub fn to_string_lossy(&self) -> String;                 // 진단용
    pub fn as_units(&self) -> &[u16];
}
pub fn is_js_whitespace(unit: u16) -> bool;

pub enum JsValue { Undefined, Null, Bool(bool), Number(f64), String(JsString), Array(Vec<JsValue>), Object(JsObject) }
/// JS 자기 키 순서: 배열 인덱스 키(0..=4294967294, 앞자리 0 없음) 오름차순, 나머지는 삽입 순서. 덮어쓰기는 자리를 유지한다.
pub struct JsObject { /* 구현 자유 */ }
impl JsObject {
    pub fn new() -> Self; pub fn get(&self, key: &JsString) -> Option<&JsValue>;
    pub fn insert(&mut self, key: JsString, value: JsValue); pub fn remove(&mut self, key: &JsString) -> Option<JsValue>;
    pub fn iter(&self) -> impl Iterator<Item = (&JsString, &JsValue)>; pub fn len(&self) -> usize;
}
pub enum JsonMode { Standard, Lossless }   // Lossless = BCJSON(M0 계획 Task 5와 같은 문법, F64 토큰 제외)
pub fn parse_json(text: &[u8], mode: JsonMode) -> Result<JsValue, JsError>;   // JSON.parse 의미, 반복 구현(재귀 없음)
pub fn parse_json_utf16(text: &[u16], mode: JsonMode) -> Result<JsValue, JsError>; // JS 문자열(WTF-16)에 JSON.parse. 문자열 안 원문 단독 서로게이트를 받는다(리뷰 C5)
pub fn stringify_json(value: &JsValue, mode: JsonMode) -> Vec<u8>;             // JSON.stringify 의미(Standard) / 무손실(Lossless)

pub fn time_clip(ms: f64) -> f64;
pub fn days_from_civil(year: i64, month: u32, day: u32) -> i64;
pub fn civil_from_days(days: i64) -> (i64, u32, u32);
pub fn date_utc(year: f64, month0: f64, day: f64, hour: f64, minute: f64, second: f64, ms: f64) -> f64; // Date.UTC
pub fn to_iso_string(ms: f64) -> Option<String>;      // Date.prototype.toISOString(±YYYYYY 포함), 범위 밖은 None
pub fn parse_iso_date(s: &str) -> Option<(i32, u32, u32)>;          // M0 시간대 계약 v1의 엄격 파서
pub fn parse_iso_clock(s: &str) -> Option<(u32, u32, u32)>;

pub struct JsError { pub name: &'static str, pub message: JsString, pub code: Option<String> }
```
- **`parse_json`(Standard)**
  - 공백은 SP·TAB·LF·CR만 허용한다.
  - 숫자는 `str::parse::<f64>`로 정확히 반올림한다. `1e400`은 Infinity, `-0`은 -0이다.
    - 예외: 명시 지수가 큰 리터럴(앞의 0을 뺀 지수 숫자 6자리 이상)은 그대로 넘기지 않는다. Rust 1.98.1 dec2flt가 명시 지수를 65536 근처에서 포화시켜, 자릿수로 지수를 상쇄한 입력(`"0." + "0"×700000 + "1e700001"`, JS는 1)을 0이나 Infinity로 읽기 때문이다. 첫 유효 숫자의 지수를 포화 연산으로 구해 넘침·밑넘침을 가르고, 그 사이는 `d.ddd…e<지수>`로 정규화해 읽는다(리뷰 C4).
  - 중복 키는 마지막 값이 이기고, 처음 자리를 유지한다.
  - `__proto__`는 평범한 키다.
  - 단독 서로게이트 `\uD800`을 허용한다.
  - 오류는 `SyntaxError`(문구는 엔진마다 다르므로 이름만 계약이다).
- **`stringify_json`(Standard)**
  - `-0`은 `0`, 비유한 수는 `null`이다.
  - 객체 안의 `undefined`는 키째 빠지고, 배열 안의 `undefined`는 `null`이 된다.
  - 이스케이프는 `\"`, `\\`, `\b`, `\f`, `\n`, `\r`, `\t`이고, 나머지 C0는 `\u00xx`(소문자)다.
  - 단독 서로게이트는 `\udxxx`(소문자)다.
  - `/`, DEL, U+2028/2029는 그대로 쓴다.
  - 숫자는 `number_to_string`으로 쓴다.
