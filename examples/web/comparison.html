Compare change from an explicit baseline

Two host-supplied synthetic series share one linear percent-change axis. Pick an exact UTC baseline and Apply. Each series uses its own raw value at that same timestamp. Pan and zoom keep the baseline fixed. The table retains raw observations; missing timestamps and explicit gaps stay gaps.

The signed calculation is (value − base) / base × 100, including negative bases. It is a mathematical percent change, not a return calculation for negative-price instruments. Values before the chosen baseline are retrospective. No dividends, splits, currency conversion or market adjustments are inferred. No data is fetched.

This is an example-local recipe using existing alignment and general series. Node analytical and modeled Canvas/DOM checks only; actual-browser, assistive-technology and native SDK validation remain unrun.
