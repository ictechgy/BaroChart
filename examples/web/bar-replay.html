Manual historical bar replay

This isolated replay reveals host-supplied synthetic OHLCV bars. Enable manual stepping, then press Next bar. There is no automatic playback or background timer. Seek uses the number of revealed bars and pauses; Reset returns to 64. Each changed position stages a new prefix; eligible forward steps reuse study endpoints, while seek/reset calculate cold. The maximum source is 65,536 bars with four SMA/EMA/RSI studies; this is a bounded manual preview, no constant-time step or latency guarantee.

No live feed, orders, fills, PnL, strategy recommendations, drawings or pan/zoom controls. Node core and modeled Canvas/DOM checks only; actual-browser, assistive-technology and native SDK checks remain unrun.

Explicit Save/Load uses this browser's localStorage for metadata only. Load uses the same synthetic dataset binding and creates a fresh paused replay. Bars, timestamps, account data and orders are not saved; nothing loads automatically.
