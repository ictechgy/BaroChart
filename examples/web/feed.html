데이터 연결 레시피

로컬 HTTP 초기 조회와 SSE 실시간 구독을 연결합니다. 모든 시세는 합성 데이터이며 실제 시장이나 주문 서버에 연결하지 않습니다. 저장소에서 node scripts/serve-feed.mjs로 실행하세요.

연결 버튼으로 시작하세요.

확인할 흐름
  1. 연결 후 현재 봉 갱신·추가·과거 수정을 적용합니다.
  2. 중복 전송은 봉과 거래량을 다시 바꾸지 않습니다.
  3. 순번이 누락되면 수락된 데이터를 유지하고 연결을 멈춥니다. 재연결 버튼으로 새 스냅샷을 받아 복구합니다.
  4. 다른 탭으로 전환하면 구독을 닫고 돌아올 때 새 스냅샷을 받습니다. 사용자가 일시 정지한 상태는 유지합니다.

실제 공급자는 스냅샷과 스트림이 공유하는 순번·watermark 계약을 제공해야 합니다. 시각이나 도착 순서만으로 최신성을 판단하지 않습니다. 이 예제는 256봉으로 제한되며 자동 삭제·자동 재시도는 하지 않습니다.
