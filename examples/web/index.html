원본과 화면의 분리

지표는 전체 원본 봉으로 계산합니다. 축소 화면에서는 OHLCV 보존 축약과 선의 최소·최대 구간을 그립니다.

사용자의 데이터

UTC 밀리초 OHLCV와 Float64Array 컬럼을 받습니다. 캘린더·휴장·수정주가 규칙은 외부 설정입니다.
