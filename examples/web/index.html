배치 저장과 복원

배치 파일을 현재 시세에 적용할 때 도형과 이력은 유지합니다. 다시 방문하면 합성 시세를 새로 만듭니다. 도형은 「도형 저장」으로 따로 보관하세요.

배치를 기억하면 다음 방문에도 지표와 패널 설정을 복원합니다.

탐색 ON: ←→ 봉, ↑↓ 표시 시리즈, Home/End 처음/끝, Enter 값 읽기, Esc 종료. 이동은 계산하지 않습니다. 값 읽기는 dirty 지표의 동기 계산으로 오래 멈출 수 있습니다. 화면 자동 이동은 하지 않습니다.

원본과 화면의 분리

지표는 전체 원본 봉으로 계산합니다. 축소 화면에서는 OHLCV 보존 축약과 선의 최소·최대 구간을 그립니다.

사용자의 데이터

UTC 밀리초 OHLCV와 Float64Array 컬럼을 받습니다. 캘린더·휴장·수정주가 규칙은 외부 설정입니다.
