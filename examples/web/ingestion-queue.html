Manual ingestion queue

Main chart · Synthetic OHLCV only. No provider connection, timer or automatic retry.

What to try
  1. Enqueue four times. The queue holds 8 events, but source bars are unchanged.
  2. Enqueue again: the complete 2-event packet is rejected. Drain once or twice, then explicitly offer again.
  3. Pause retains accepted events. Resume does not drain them.
  4. With pending events, replace the source timeline. Resume explicitly rebinds source version; the next Drain rejects old-timeline events without consuming them. Cancel explicitly discards them and any unaccepted offer without reusing accepted sequences. Pause state is unchanged.

Updates replace cumulative volume; they do not sum snapshots. The source-stale button deliberately moves every stored bar one day forward. The old queue is retained to demonstrate failed drain and explicit cancellation. Real overlapping provider snapshots need a host freshness policy. After reaching 64 stored bars, drain may fail and retain the queue; cancel or reload this example. Automatic eviction and compaction are outside this example. Keyboard/assistive-technology behavior has not been device-tested.
