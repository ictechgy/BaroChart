내 차트 UI / UX

웹 호스트용 선택 기능입니다. 기본 데모는 그대로이며, 자동 복원하지 않으므로 새로고침하면 초기화됩니다. 입력·도구 모음만 아래 버튼으로 명시적으로 저장하고 불러올 수 있습니다. 도형 저장 파일에는 UI 설정이 포함되지 않습니다.

입력 동작

모바일은 24px 선택 반경·44px 최소 버튼 높이·휠 줌 꺼짐을 사용합니다. 기기를 자동 감지하지 않습니다.

끄면 해당 입력을 소비하지 않습니다. API와 도구 모음은 계속 사용할 수 있으며, 별도의 데이터 탐색 모드는 단축키 설정과 독립적입니다.

차트 패널

패널 높이 비율과 축 위치만 바꿉니다. 패널 드래그 재배치나 네이티브 UI 설정은 아닙니다.

전체 구간의 종가 표본과 현재 범위를 보여줍니다. 최소 범위는 기존 차트의 10봉 규칙을 따릅니다.

합성 데이터의 표시 전용 마커이며 클릭하면 호스트 콜백에 ID만 전달합니다. 주문·체결 수집·저널 저장은 하지 않습니다.

고정 모서리 슬롯이며 가격·시간 앵커나 자유 도킹이 아닙니다.

이 브라우저의 로컬 저장소를 사용합니다. 색상·패널·위치·드로잉·데이터는 이 버튼으로 저장하지 않습니다.

준비 중…

도구는 Tab으로 이동합니다. 차트에 포커스하면 화살표 팬, +/− 줌, Esc 취소, Ctrl/Cmd+Z 되돌리기를 사용할 수 있습니다. 임의 색상은 대비를 자동 보정하지 않으므로 직접 확인하세요.

새 컨트롤은 Node의 모의 DOM으로 검증했습니다. 실제 브라우저 레이아웃·터치·스크린 리더 검증은 아직 수행하지 않았습니다.
